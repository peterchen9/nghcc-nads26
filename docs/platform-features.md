# 北門行政平台功能說明

本文件依 2026-08-05 正式主機 `/home/apps1/nads26` 的程式快照整理。功能是否可見及可操作，仍以登入者的選單授權、管理員身分與正式資料狀態為準。

## 入口、帳號與權限

- 首頁與自訂內容頁：顯示平台入口、公告或管理者維護的頁面內容。
- 帳號登入／登出、變更密碼及電子郵件密碼重設流程。
- 使用者管理：建立、編輯使用者，維護姓名、員工編號、啟用狀態與可使用的選單。
- 選單權限：超級管理員可看到全部啟用項目；一般使用者依個別允許的選單項目顯示與限制路由。
- Django Admin：供具備管理權限者維護系統模型資料。

## 會友、牧區與同工行政

### 會友資料（Eureka）

- 會友查詢、個人資料檢視與照片顯示。
- 新增、修改、刪除及重複資料檢查。
- 會友資料下載與批次匯出。
- 依姓名、教會編號及既有組織資料進行查找與整理。

### 牧區組織

- 牧區總覽與牧區長維護。
- 區、小組的新增及編輯。
- 查詢小組成員、加入／移除組員及檢視未分組會友。
- 牧養關懷報告填寫、管理清單及 PDF 報表。

### 同工資料與休假

- 同工清單、同工資料新增／編輯／刪除，以及帳號與員工編號關聯。
- 「我的休假」月曆：申請與查看個人上午／下午休假、鎖定月份及剩餘額度資訊。
- 「全體月表」：按月查看所有同工休假與行政／教會備註。
- 休假資料同步及既有休假紀錄匯入命令。
- 同工個人資料、密碼變更、教會行事曆與費用申請入口。

### 出席與輪班

- 主日崇拜出席資料：日期查詢、統計與既有資料匯入。
- 年度／每週出席資料與禱告會出席紀錄。
- 會議出席管理。
- 同工班別、輪班清單及新增／編輯／刪除班次。
- 座位圖編輯與保存。

## 崇拜與禮儀

- 詩歌資料庫：詩歌清單、詳細資料、檔案上傳及禮拜詩歌頁面。
- 網路影音：讀取影音資訊與下載影音內容。
- 洗禮：梯次、報名者、會友資料連結、編輯及批次完成。
- 安息禮：案件建立／編輯、入殮與安葬等資訊、批次完成及服事輪班。
- 聖餐禮、婚禮與歷屆執事名單目前由系統標示為建置中頁面。
- 小會／執事會會議紀錄管理。

## 場地、設備與網路

### 場地預約

- 場地預約月曆與每日總覽。
- 場地／教室管理及預約資料匯出。
- 既有場地預約頁面與整合入口。

### 教室巡檢

- 教室巡檢總覽、房間與巡檢項目 API。
- 行動版逐間巡檢頁面。
- 房間 QR Code 與巡檢 PDF 匯出。

### 定期保養與一般維修

- 定期保養項目與保養紀錄管理。
- 保養報告、單項設備 QR Code 及 API。
- 一般維修案件：建立、查詢、編輯、刪除、附件與未完成案件。
- 維修分類、地點、廠商、統計儀表板。
- 對外維修通報入口。

### 電力與網路

- 每日電力報告與 API。
- LAN 主機掃描、備註、Ping 狀態。
- WLAN AP 掃描與狀態頁面。
- 網路盤點同時存在 facility 整合入口與 network 模組路由。

## 財務與申請

- 預算項目：清單、新增／編輯、刪除、異動紀錄與匯出。
- 預算項目依頁面群組分派，配合使用者選單權限限制操作範圍。
- 銀行帳戶餘額與定期存款管理。
- 基金、團契及其每月餘額管理。
- 每月／年度奉獻金額與人數統計。
- 財務、場地及同工入口共用費用申請與傳票 PDF。
- 銀行餘額、基金／團契餘額及奉獻統計均提供既有資料匯入命令。

## 教育課程

- 課程建立、編輯、刪除、清單與詳細頁。
- 課程看板與各堂課紀錄。
- 課程錄音上傳與授權播放。
- 補課登記及完成狀態。
- 課程文件中心，可產生公告、門牌、意見回饋與出席表。
- 課程總紀錄與課程 QR Code。

## 文件、媒體與工具

- 同工參考資料中心：目錄瀏覽、上傳、下載與檔案註記。
- 記錄檔案操作歷程，並限制請求路徑不得跳出設定的資料根目錄。
- 媒體資料庫：掃描 NAS 媒體、瀏覽、下載及產生編輯用下載內容。
- QR Code 產生器。
- CKEditor 上傳整合，供內容頁及相關表單使用。

## 資料與批次維運

正式程式包含下列管理命令或維運腳本；執行會影響資料，必須先備份並另行核准：

- 套用標準選單權限。
- 匯入銀行餘額、基金／團契餘額及奉獻統計。
- 匯入休假、崇拜出席及同步同工出席。
- 匯入教會維修紀錄。
- 掃描 LAN 主機及 NAS 媒體。
- 會友分類、牧區結構重建、遠端 SQLite 同步、Wi-Fi 標籤等工具。

## 架構與持久化資料

- Django Web 容器 `nads26-web` 透過 bind mount 使用 `/home/apps1/nads26:/app`。
- MySQL 8.0 容器 `nads26db` 保存主要業務資料。
- `media`、`static`、`private_media`、外部檔案中心目錄及 NAS 來源承載上傳或生成內容。
- 正式環境入口由 Nginx 提供 HTTPS，轉送到主機 `26001`／容器 `8000`。
- `.env`、SQL dump、資料庫實體檔、媒體、log 與備份皆不得提交 GitHub。

## 已知狀態與限制

- 聖餐禮、婚禮、歷屆執事名單及部分選單項目仍顯示「建置中」。
- 實際可見功能由資料庫中的動態選單及使用者授權控制，程式存在不代表所有帳號皆可操作。
- 部分功能依賴 NAS、外部 SQLite、網路掃描或既有檔案路徑；在開發環境可能無法完整重現。
- 正式主機程式目錄未包含 Git metadata；正式更新後必須把安全程式快照同步回 repository，避免 GitHub `main` 再次落後正式版。
